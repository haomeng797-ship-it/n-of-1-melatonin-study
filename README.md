# What Organizes Daily Affect in One Person

*A 70-day N-of-1 characterization with a nightly melatonin probe.*

*Revised manuscript submitted to the Journal for Person-Oriented Research*

A 70-day single-subject self-experiment that asks whether nightly melatonin predicts
daily affective state, framing the individual as a dynamical system and treating
melatonin as a probe of that system rather than as a candidate treatment. Two internal
variables (perceived agency and metacognitive awareness) jointly explained 52.8% of
daily-mood variance beyond autoregressive carryover and the probe (40.5% with a linear
time trend), whereas melatonin added 0.02%. Mood varied less on melatonin days, but no test of
that difference reached significance (strongest: α₁ = −1.24, *p* = .149).

**Author:** Miura Meng · meng10@upenn.edu · ORCID [0009-0004-1522-1997](https://orcid.org/0009-0004-1522-1997)

**Keywords:** N-of-1; ecological momentary assessment; dynamical systems; autoregressive
model; idiographic; personal science; intensive longitudinal data; affect dynamics

## Repository layout

- `randomization/`: pre-specified 70-day schedule (`schedule.json`) and protocol
- `data/`: the archived observation-level EMA log (`miura_ema_70day.csv`, n = 195, every record that was entered) and the day-level frame derived from the analytic set (`miura_ema_70day_daily.csv`, n = 70, regenerated by `01_data_prep.py`)
- `src/data_logger.py`: iOS Shortcuts entry validation
- `src/analysis/`: analysis scripts `01`–`15` (run order below)
- `outputs/`: cleaned frames (`clean_obs.csv`, n = 193, and `clean_day.csv`), the two records the inclusion rule drops (`excluded_observations.csv`), model tables, and `results_table.csv` (the consolidated headline numbers). Diagnostics quoted in the paper have their own files: `m2_diagnostics.csv` (VIF, condition number, residual tests), `ar_order_same_window.csv` and `ar_order_fit_comparison.csv` (Day 18–70 lag order), `ar_order_by_resolution.csv` (Appendix A), `metacontrol_simple_slopes.csv`, `equivalence_tost.csv`, `multilevel_table.csv` and `multilevel_fit_stats.csv`, `time_trend_sensitivity.csv` (time-trend sensitivity analysis), `response_timing.csv` (response timing), `first_difference_and_lag.csv` (first-difference model and lagged melatonin term) `multilevel_within_between.csv` (within-day and between-day coefficients), `lagged_model.csv` (lagged model of the three daily series, Appendix C.4) and `split_at_interim.csv` (estimates before and after the interim analysis, Appendix C.5), all added in the revision
- `figures/`: the six figures of the revised manuscript from `06_make_figures.py` (`fig1`–`fig3` and `figA1`–`figA3` for Figures 1–3 and A.1–A.3), plus `equivalence_tost_plot.png` from `10_equivalence_test.R`

## Reproducing the analysis

Python 3.10+ (`pip install -r requirements.txt`), run from the repository root:

```bash
python src/analysis/01_data_prep.py                    # apply the inclusion rule, build the analytic set
python src/analysis/02_ar1_models.py                   # nested AR(1) models + incremental R²
python src/analysis/02b_ar1_obslevel.py                # observation-level AR(1) + half-life
python src/analysis/03_state_space.py                  # local-level Kalman filter
python src/analysis/04_metacontrol.py                  # melatonin × metacognition interaction
python src/analysis/05_variability_and_interactions.py # variability, interactions, state-dependence
python src/analysis/08_results_table.py                # assemble results_table.csv
python src/analysis/12_time_trend_sensitivity.py       # refit with a linear time term
python src/analysis/13_response_timing.py              # distance of responses from prompt times
python src/analysis/14_first_difference_and_lag.py     # first differences; one-day lag of melatonin
python src/analysis/15_lagged_model_and_split.py      # lagged model of the three series; split at Day 44
python src/analysis/06_make_figures.py                 # regenerate the figures
```

Robustness analyses run in R (≥ 4.1):

```r
source("src/analysis/09_multilevel_robustness.R")  # mixed-effects (lme4)   -> Table B.1
source("src/analysis/10_equivalence_test.R")       # TOST equivalence       -> §3.3
source("src/analysis/11_ar_order_check.R")         # AR(1) vs AR(2) by resolution -> Appendix A
source("src/analysis/07_bayesian_robustness.R")    # Bayesian M2 (brms), reported here only
```

The Bayesian re-estimation places the coefficients in the same order as the daily-level
M2. The multilevel model works at the momentary resolution and ranks the two internal
predictors the other way round; what holds across all three is the gap between the
internal block and the probe. It is kept in this repository and referenced from the
manuscript rather than tabulated there.

Verify the archived randomization schedule against the protocol constraints:

```r
source("randomization/verify_schedule.R")          # 35/35 days, no run > 2
```

Every number in the manuscript can be recovered from `outputs/`, and every figure in the
repository is current output from the scripts above; nothing is hand-edited.

## Method in brief

A 70-day alternating-treatment design randomized each day to melatonin or control (no
run longer than two consecutive days). EMA was collected three times daily (~10:00,
16:00, 22:00) via iOS Shortcuts: mood, agency, and metacognition typed as 0–100 numbers plus
a melatonin indicator. Agency and metacognition were added on Day 18, so analyses using
them cover Days 18–70. The raw log holds 195 records; 193 of them fill one of the 210
planned prompt slots, so the analytic sample is 193 scheduled observations across 70
study days (91.9% scheduled-response compliance), with 35 control and 35 melatonin days.
Two records entered on 2026-04-03, after that study day's prompts had been completed the
day before, stay in the archived log and are excluded from every analysis.
